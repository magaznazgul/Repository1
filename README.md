# SQL Query Builder

## Жоба туралы

Бұл жоба SQL Query Builder бағдарламасын Builder паттерні арқылы жүзеге асыруға арналған.

Бағдарлама пайдаланушыға SQL сұраныстарын графикалық интерфейс арқылы қадамдық түрде құрастыруға мүмкіндік береді. Кестені, бағандарды, WHERE шарттарын, сұрыптау параметрлерін және нәтижелер санын таңдауға болады.

## Қолданылған технологиялар

- Java
- Java Swing
- Builder Design Pattern
- SQL

## Бағдарламаның мүмкіндіктері

- Кестені таңдау (`users`, `products`, `orders`).
- Қажетті бағандарды таңдау.
- WHERE шарттарын қосу және жою.
- Шарттар үшін операторларды таңдау (`=`, `!=`, `>`, `<`, `>=`, `<=`, `LIKE`).
- AND және OR логикалық операторларын қолдану.
- ORDER BY арқылы сұрыптау.
- LIMIT арқылы нәтижелер санын шектеу.
- SQL сұранысын генерациялау.
- Генерацияланған сұранысты көшіру.
- Сұраныс параметрлерін бөлек көрсету.

## Builder паттернінің қолданылуы

Жобада `QueryBuilder` интерфейсі және оны жүзеге асыратын `SQLQueryBuilder` класы қолданылады.

Builder паттерні SQL сұранысын бірнеше кезең арқылы құрастыруға мүмкіндік береді. Әрбір әдіс сұраныстың белгілі бір бөлігін қосады.

## SQL Injection қауіпсіздігі

Пайдаланушы енгізген мәндер SQL сұранысына тікелей біріктірілмейді. Олардың орнына `?` параметрлік белгілері қолданылады. Бұл тәсіл SQL Injection қаупін азайтуға көмектеседі.

## Іске қосу

1. Жобаны компьютерге жүктеп алыңыз немесе клонданыз.
2. Жобаны IntelliJ IDEA немесе басқа Java IDE бағдарламасында ашыңыз.
3. `Main.java` файлын ашыңыз.
4. Бағдарламаны іске қосыңыз.

## Ескерту

Бұл бағдарлама SQL сұраныстарын құрастырады және көрсетеді. Деректер базасына қосылу немесе сұраныстарды орындау қарастырылмаған.
